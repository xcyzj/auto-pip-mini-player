# 视频划出视口 · 自动小窗与画中画

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

油猴脚本（UserScript）：**视频播放器划出视口时自动变成页面内的悬浮小窗**，像哔哩哔哩那样 —— 你继续往下看评论、刷推荐，视频缩到角落接着播。也可以切换成浏览器的**系统画中画**（真正的独立悬浮窗，可跨标签页）。

与常见"重新实现一个播放器"的做法不同，本脚本**复用站点自己的播放器**：把播放器容器整体等比缩小，控制条、画质菜单、弹幕开关全部跟着变小，因此不依赖任何站点专有接口，也不接管播放逻辑。

> 默认只在已实测的站点生效（见下方 `@match`）。其它站点需要你手动加一条规则，见 [给更多站点启用](#给更多站点启用)。
>
> 问题反馈 / 建议：<https://github.com/xcyzj/auto-pip-mini-player/issues>

---

## 特性

- **站内小窗（默认）**：划出视口即缩到角落，保留站点自带控制条与全部功能，可拖动、可缩放、位置与尺寸记忆。
- **系统画中画（可选）**：切换播放方式后，划出视口直接进浏览器悬浮窗；点一下页面（任意位置）再划出即可触发，不需要点脚本按钮。
- **切标签自动进画中画**：独立开关，两种模式都可用。切到别的标签页时由浏览器自动弹出画中画。
- **防跳版面**：播放器脱离文档流时在原位置留等大占位，并实测整页位移补回滚动位置，不会看到内容跳动。
- **几何补偿**：修正"用 `offsetWidth`（布局尺寸）算进度条落点"的播放器在缩放后拖动位置不准的问题。
- **站点适配器**：对结构特殊、或自带小窗的站点可单独配置（选择器 / 让位 / 禁用）。
- **轻量**：不使用覆盖全文档的 `MutationObserver`，不需要常驻后台页，单文件约 60 KB。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。
2. 安装本脚本：在 GreasyFork 脚本页点「安装」，或把 `auto-pip-mini-player.user.js` 拖进浏览器。
3. 打开已支持的视频页面，划出视频即可看到小窗。

## 快速上手

- 划出视频 → 出现小窗。小窗上沿有一条工具条：
  - `↩` 回到原位（还原到页面里；此后需要把视频重新滚回视野，滚走才会再次触发）
  - `📌` 固定（滚回原位也不自动收起）
  - `⧉` 手动进入系统画中画
  - `✕` 关闭小窗（默认还原并暂停，可在设置里改）
- 小窗右下角拖动改大小，工具条拖动改位置，位置与尺寸会被记住。
- `Alt+Shift+V` 打开设置面板（油猴菜单里也有入口）。

## 两种播放方式

| | 站内小窗（默认） | 系统画中画 |
| --- | --- | --- |
| 出现方式 | 划出视口即出现 | 先在页面上点一下（任意位置），再划出视口 |
| 是否跨标签页 | 否（只在当前页面） | 是（真正的独立窗口） |
| 触发不了时 | 一定能出小窗 | 什么都不做，**不会退回小窗** |
| 手动入口 | 工具条 `⧉` / 菜单 | 同左 |
| 额外能力 | 拖动、缩放、位置记忆 | 滚回视野时自动收起（可关） |

两种方式是互斥的：选了系统画中画就不会再出现站内小窗。

> 系统画中画必须由**一次真实的用户点击**触发（浏览器给约 5 秒的"瞬时激活"窗口）——页面上随便点一下即可，不必点脚本按钮。切标签自动进入那条路不需要手势，但需要站点已被浏览器授权（地址栏站点信息里的"自动画中画"，或首次弹窗时选允许）。

## 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 播放方式 | 站内小窗 | 小窗 / 系统画中画 |
| 切标签时自动进画中画 | 关 | 独立开关，两种模式都生效；需一次性授权 |
| 滚回视野时自动收起画中画 | 开 | 只对"划出视口后进入"的画中画生效 |
| 小窗 ✕ 的行为 | 还原并暂停 | 或"仅还原，继续播放" |
| 缩放锁定比例 | 开 | 拖右下角时保持视频比例 |
| 暂停时自动收起 | 关 | 暂停即还原 |
| 必要时搬到顶层宿主 | 开 | 播放器祖先带 `transform` 时临时搬到顶层，避免定位跑偏 |
| 几何补偿 | 开 | 见下方说明 |
| 站点适配器 | `{}` | 按 host 配置，见下方说明 |

### 几何补偿是什么

有些播放器用 `offsetWidth`（**布局尺寸**）来计算进度条落点。脚本用 `transform` 缩放时布局尺寸不变（例如仍是 640px，而视觉上只有 360px），于是"鼠标位置 ÷ 布局宽度"就会偏，拖进度条落点不准。

开启几何补偿后，脚本会在小窗存在期间把**容器子树内**读到的 `offsetWidth / offsetHeight / clientWidth / clientHeight` 乘以缩放系数，让播放器读到视觉尺寸；还原时恢复原型上的原始描述符（不污染页面上的其它脚本）。只在小窗存在期间、只对该容器子树生效。

如果某个站点因此出现布局异常，关掉这一项即可。

## 给更多站点启用

脚本**不含内部白名单**，作用范围完全由油猴的「包含/排除」决定（脚本无法修改自己的 `@match`，那些元数据只在决定是否注入页面时被读取一次）。

两种加法：

1. **油猴界面（推荐）**：油猴图标 → 本脚本 → 设置页 →「包含/排除」→ 在 **用户包含** 里点「添加…」，粘贴规则后刷新目标页面。面板里的「复制整站规则 / 复制本页路径规则」按钮可以直接把规则复制到剪贴板。
2. **改脚本源码**：在文件顶部再加一行 `@match`。

规则示例：

```
https://*.bilibili.com/*        https://*.youtube.com/*
https://v.qq.com/x/*            https://v.youku.com/*
https://*.iqiyi.com/*           https://www.mgtv.com/*
https://*.douyin.com/*          https://weibo.com/*
https://*.zhihu.com/*           https://*.acfun.cn/*
https://vimeo.com/*             https://www.twitch.tv/*
```

想更精确就带上路径前缀，例如 `https://www.miyoushe.com/ys/article/*`（`@match` 不支持正则，需要正则时用 `@include /^https:\/\/.../`）。

## 站点适配器

按 host 配置（面板里的「站点适配器 (JSON)」），用于处理结构特殊的站点：

```json
{
  "www.example.com": {
    "videoSelector": "video.main",
    "containerSelector": ".player-wrapper",
    "nativeMiniPlayer": false,
    "disabled": false
  }
}
```

| 字段 | 说明 |
| --- | --- |
| `videoSelector` | 页面上有多个 `<video>` 时，指定接管哪一个 |
| `containerSelector` | 指定小窗要固定的播放器容器（默认自动推断最贴近视频的那层） |
| `nativeMiniPlayer` | 该站点自带小窗（如 B 站、YouTube），设 `true` 让位、本脚本不接管 |
| `disabled` | 该站点完全禁用 |

自动推断的规则（没有配置 `containerSelector` 时）：从 `<video>` 逐层向上，取"尺寸和视频一致、或只多出控制条那一小块"的祖先；一旦某层明显变大、或比上一层多出一大段文字（说明把标题/正文包进来了），就停止。遇到推断不准的站点，用 `containerSelector` 指定最省事。

## 工作原理（简述）

1. 用定时心跳（1.5s）+ `IntersectionObserver` 找到正在播放的 `<video>`，并推断它的播放器容器。
2. 容器划出视口时，把它 `position: fixed` 到角落，**保持原始宽高**，用 `transform: scale()` 整体缩小 —— 站点内部的控制条、字号、图标、视频尺寸按同一比例一起变小，播放器内部布局不受影响。
3. 在原位置插入一个复刻原盒子（`display` / `margin` / `flex` / 尺寸）的占位元素：既撑住版面，也作为"滚回原位"的判定参照。
4. 改版面前后各测一次页面上参照元素的位置，整页位移多少就把滚动位置补回多少。
5. 可选：把容器子树内的尺寸读取换算成视觉尺寸（几何补偿）。

## 已知限制

- **跨域 iframe 内的播放器**不支持（脚本以 `@noframes` 只在顶层框架运行）。
- **站点自带小窗**（B 站、YouTube 等）可能与本站脚本抢同一块区域，用 `nativeMiniPlayer` 让位。
- **硬跳转**（整页刷新/换页）会丢掉小窗；站内 SPA 换页可以保持。
- **DRM / canvas 自绘播放器**（部分流媒体）无法接管。
- **进度条类控件**依赖站点的实现方式：用布局尺寸算落点的需要几何补偿，用指针坐标换算的（少数）无法修复。
- **切标签自动进画中画**受浏览器策略约束（需要授权、需要有声音且正在播放、需要持有音频焦点），未授权时不会有任何反应。

## 常见问题

**划出视频没有小窗？**
确认脚本已在该站点运行（油猴图标里能看到本脚本的菜单），以及当前页面 URL 命中了包含规则。

**小窗位置乱了／想重置所有设置？**
设置面板里的「恢复默认」会重置配置并清除位置记忆。

**某个站点不想要这个脚本？**
在该站点的油猴「用户排除」里加一条规则即可，无需改脚本。

**和站点自带的小窗打架？**
给该站点配 `{"nativeMiniPlayer": true}`。
